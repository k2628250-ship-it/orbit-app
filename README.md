# Орбита

**Компактный «динамический остров» для Windows: музыка с караоке, заметки, таймер, события, темы и дистанционные обновления. Один EXE, без установки.**

Орбита — небольшое плавающее окно в верхней части экрана, которое всегда под рукой, но не мешает: оно не показывается в Alt+Tab и не занимает место на панели задач. Свёрнутая таблетка **416×62**, раскрытая панель **832×559** (масштабируется).

## Возможности

- **Музыка.** Подхватывает активный плеер через Windows SMTC, показывает обложку в виде вращающейся пластинки, эквалайзер, длительность, повтор и плейлист. Если браузер сообщает «Paused», а звук реально идёт, Орбита определяет воспроизведение по WASAPI — пластинка крутится и слова не замирают.
- **Караоке.** Синхронные слова песни прямо в свёрнутой таблетке. Капсула автоматически расширяется на всю строку и сжимается, когда предложение спето. Текст кэшируется локально и продолжает работать без интернета.
- **Заметки и напоминания.** Автосохранение, цветные маркеры, быстрые напоминания, отправка текста в ИИ.
- **Таймер и Pomodoro.** Произвольное время и пресеты, круговой прогресс, звук завершения, режим «25 минут без уведомлений».
- **События и контекст.** Лента событий с фильтрами, локальный поиск, сводка дня, запросы доступа к микрофону, умный буфер обмена.
- **Погода, календарь, система.** Погода по городам, ближайшие события `.ics`, заряд батареи, сеть, сезонные эффекты.
- **Полка и телефон.** История файлов, удаление с восстановлением, QR-код для передачи файлов по локальной сети.
- **Персонаж и темы.** Живой питомец, дюжина тем, радужный акцент, скругления и звуки интерфейса.
- **Горячие клавиши.** `Ctrl+Alt+I` — показать/скрыть, `Ctrl+Space` — быстрое открытие, `Ctrl+Shift+N` — новая заметка, `Ctrl+Shift+H` — скрытый режим.

## Установка

1. Скачайте `Orbit-1.0.1-win-x64.exe` из раздела **Releases**.
2. Запустите файл — установка не требуется, .NET ставить не нужно (всё уже внутри EXE).
3. Нажмите `Ctrl+Alt+I` или кликните по таблетке, чтобы открыть панель.

Поддерживаются **Windows 10 (2004 и новее)** и **Windows 11**, x64.

## Автообновление

Орбита умеет обновляться сама. Достаточно один раз указать прямую ссылку на `update.json` в **Настройки → Автообновление** (или пункт трея «Проверить обновления»). При каждом запуске приложение:

- сверяет версию с манифестом;
- скачивает новый EXE и проверяет SHA256;
- безопасно заменяет запущенный файл и перезапускается;
- сохраняет все настройки и данные.

Если сервер недоступен, Орбита просто продолжает работать — без ошибок на экране.

Формат `update.json`:

```json
{
  "version": "1.0.2",
  "url": "https://.../Orbit-1.0.2-win-x64.exe",
  "sha256": "необязательно, но рекомендуется",
  "notes": "необязательно"
}
```

Версия должна быть старше текущей. Относительный `url` считается от папки манифеста.

## Где хранятся данные

- Настройки: `%APPDATA%\Orbit\settings.json`
- Лог: `%LOCALAPPDATA%\Orbit\log.txt`
- Кэш текстов песен: `%APPDATA%\Orbit\Lyrics`
- Полка и история файлов: `%APPDATA%\Orbit\Shelf`

Никакой телеметрии нет. Ключи ИИ вводятся пользователем и остаются локально.

## Сборка из исходников

```powershell
dotnet publish Orbit.csproj -c Release -r win-x64 --self-contained true -p:Platform=x64 -p:DebugType=none -o publish\Orbit
```

Однофайловая сборка:

```powershell
dotnet publish Orbit.csproj -c Release -r win-x64 --self-contained true -p:Platform=x64 -p:DebugType=none ^
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true ^
  -p:EnableCompressionInSingleFile=true -o publish\Orbit-SingleFile
```

## Ограничения

- Провайдеры ChatGPT / Gemini / DeepSeek требуют собственного ключа или proxy-endpoint.
- Живые субтитры используют микрофон Windows; звук сторонних видео и YouTube не перехватывается.
- Передача файлов на телефон работает в доверенной локальной сети (`http://192.168.x.x:8798`).
- Локальные HTTP-сервисы на портах 8798/8799 не требуют авторизации — используйте их только в доверенной сети.
